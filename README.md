# ⚔ CharacterForge

Web character sheet for TTRPGs — D&D 5e SRD 5.2, with JSON import support for custom systems.

**[Live demo →](https://Athryell.github.io/CharacterForge)**

---

## Features

- **Automatic calculations** — modifiers, proficiency bonus, spell save DC, initiative, passive perception
- **Clickable proficiencies** — click = proficiency, click again = expertise, click again = remove
- **Dynamic HP bar** — color shifts green → orange → red
- **Spell slots** — auto-generated by class and level, restored on long rest
- **Action filters** — Action / Bonus / Reaction / Free
- **Death saving throws**, inspiration, automatic hit dice
- **Import / Export JSON** — documented schema, compatible with custom formats
- **PWA** — installable on mobile and desktop
- **Automatic dark mode**

## Quickstart

```bash
git clone https://github.com/Athryell/CharacterForge
cd CharacterForge
npm install
npm start
```

Opens `http://localhost:3000`.

---

## Deploy to GitHub Pages

```bash
# 1. Update homepage in package.json with your username
#    "homepage": "https://<YOUR-USERNAME>.github.io/CharacterForge"

npm install
npm run deploy
```

`npm run deploy` builds and publishes to GitHub Pages automatically.

---

## Deploy to itch.io

```bash
npm run build
```

Zip the `build/` folder and upload it to itch.io as an HTML game.
Set "Shared Externally" → Kind: HTML.
