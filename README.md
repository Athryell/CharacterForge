# CharacterForge

Free, open-source TTRPG character sheet — runs in the browser, no account required.

**[Open the app →](https://Athryell.github.io/CharacterForge)**

---

## Features

**Multi-system support**
- D&D 5.5e 2024 (SRD 5.2.1, CC BY 4.0)
- Daggerheart (SRD 1.0)

**Character management**
- Multiple characters with quick-switch
- Character creator wizard for each system
- Level up / level down with history tracking
- Long rest and short rest with slot / HP reset

**Gameplay tools**
- Automatic calculations — modifiers, proficiency bonus, spell save DC, initiative, passive perception
- Spell slots auto-generated by class and level
- Action tracker with type filtering (Action / Bonus / Reaction / Free)
- Weapon manager — mastery, properties, equipment bonuses
- Condition tracker — all SRD conditions with descriptions, exhaustion level counter
- Death saving throws, inspiration, concentration tracking
- Inventory with weight tracking and coin weight

**Customization**
- Drag-and-drop widget layout — rearrange panels per tab, pin to top bar
- Homebrew editor — add custom spells, weapons, classes, species, backgrounds, and conditions via a built-in form or JSON import
- Custom tags on items and spells

**Notation system** — use `[STR]`, `[PRO]`, `[LVL]` in any description field; values resolve dynamically. Supports scaling (`[LVL=1:1d6,5:1d8]`), pip counters (`[countCHA]`), and inline equipment bonuses (`+2@[AC]`).

**Accessibility & UX**
- Automatic dark mode (follows system preference, manual override available)
- Adjustable font size and icon mode (emoji / Lucide / text-only)
- High-contrast mode, reduce-motion support
- Speed / distance units: ft, m, or squares

**Internationalization**
- UI in EN · IT · DE · ES · FR
- Translations managed on [Crowdin](https://crowdin.com/project/characterforge)

**PWA** — installable on mobile and desktop, works offline after first load.

## Getting Started

```bash
git clone https://github.com/Athryell/CharacterForge.git
cd CharacterForge
npm install
npm start        # dev server at localhost:3000
npm run build    # production build → build/
npm run deploy   # build + push to gh-pages branch
```

No test suite. ESLint runs automatically via `react-scripts`.

## Data Architecture

### Adapter pattern

Each game system has an adapter (`dnd5eAdapter`, `dhAdapter`) that exposes its data via methods. Components never import directly from `src/data/systems/*/` — they go through `dataManager`:

```js
const { systemId } = useCharContext();
const adapter = dataManager.getAdapter(systemId);
const SCHOOLS = adapter.getSchools();
```

`dataManager.js` merges SRD data with any active homebrew sources and delegates to the correct adapter based on `systemId`.

### Notation system

Write notation tokens in any description or feature field — they resolve at render time using the current character's stats:

| Token | Resolves to |
|---|---|
| `[STR]` `[DEX]` … `[PRO]` | Ability modifier / proficiency bonus |
| `[LVL]` `[LVL/2]` | Character level / half level |
| `[LVL=1:1d6,5:1d8]` | Scaling value by level threshold |
| `+2@[AC]` `+[PRO]@[AC]` | Inline equipment bonus badge |
| `[countPRO]` `[countCHA]` | Pip counter sized by stat |

Notation is resolved in `src/components/Tooltip.jsx` (`resolveNotations()`).

## Contributing

**Translations** — [Crowdin project](https://crowdin.com/project/characterforge). No technical skills needed; add or improve any of the five supported languages directly in the browser.

**Feedback and bug reports** — open an issue on GitHub or use the in-app feedback link.

**Homebrew** — the built-in Homebrew Editor (Settings → Sources) lets you create data packages without touching the code. Export as JSON to share with others; import via the same panel.

**Pull requests** — read `CLAUDE.md` (architecture) and `DESIGN_SYSTEM.md` (CSS conventions) before writing code. Key rules:
- Components use `dataManager.getAdapter(systemId)` — no direct imports from `src/data/systems/*/`
- All UI strings go through `t('key')` with keys added to `src/i18n/locales/en/ui.json` and `it/ui.json`
- New CSS variables go in `:root` in `src/App.css`
- Do not modify `src/hooks/useCharacter.js` or `src/chars.js`
