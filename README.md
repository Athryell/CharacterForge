# ⚔ CharacterForge

Web character sheet for D&D 5e (SRD 5.2) — installable PWA, no account required.

**[Live demo →](https://Athryell.github.io/CharacterForge)**

---

## Features

- **Multi-character management** — create, switch, and delete characters from a single screen
- **Automatic calculations** — ability modifiers, proficiency bonus, spell save DC, initiative, passive perception
- **Clickable proficiencies** — cycle through none → proficient → expertise
- **Dynamic HP bar** — color shifts green → orange → red as HP drops
- **Spell slots** — auto-generated by class and level, restored on long rest or short rest (Warlock)
- **Action tracker** — filter by Action / Bonus Action / Reaction / Free; add custom actions with dice
- **Weapon manager** — SRD presets with mastery, proficiency, and equipment bonuses
- **Inventory** — item weight tracking, coin weight, inline dice notation
- **Condition tracker** — all SRD conditions with tooltip descriptions; exhaustion level counter
- **Death saving throws**, inspiration toggle, concentration tracking
- **Notation system** — write `[STR]`, `[PRO]`, `[LVL:1d6,5:1d8]` in any description field; values resolve automatically
- **Drag-and-drop layout** — rearrange widgets and tabs, pin items to top bar
- **Homebrew data sources** — import custom spells, weapons, classes, species, and backgrounds via JSON
- **Import / Export JSON** — full character export and import
- **PWA** — installable on mobile and desktop, works offline
- **Automatic dark mode** — follows system preference; manual override available
